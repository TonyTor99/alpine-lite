# alpine-danil-lite

Лёгкий парсер alpinbet.com → **ВКонтакте (основной, картинкой)** и **Telegram**.
Один Python-процесс, чистый `requests` (без браузера, Django, Celery, Redis).

## Что делает

- Логинится в ЛК alpinbet через `requests` (csrf → `/site/login` → PJAX рассылок).
- Каждые ~10 c опрашивает активные прогнозы включённых рассылок.
- Новый прогноз:
  - **VK** — сообщение **с картинкой прогноза** (основной канал, без редактирования);
  - **Telegram** — фото с подписью; при завершении матча подпись **редактируется**
    (итог Зашло/Не зашло/Возврат + прибыль %).
- Отчёты по прибыли: **суточный / недельный / месячный**, автоотправка по часам МСК
  (статистика берётся со страницы «Прибыль» рассылки). Дедуп по периоду.
- Управление — через **Telegram-бота на инлайн-кнопках** (см. ниже). Состояние — в `state.db` (sqlite).
- Глобальная **пауза/старт** всего опроса, ручной **релогин**, **тест доставки** канала.
- **Уведомления админам** при сбоях (троттлинг/логин/сеть) + авто-«снова онлайн».
- **Асинхронная отправка** (отдельный поток-воркер): медленный TG/VK не блокирует опрос.
- **systemd-watchdog**: тихий зависон → авто-рестарт. **force IPv4** против мёртвого IPv6 к Telegram.
- **Настройки из бота** (интервал, часы отчётов, вкл/выкл автоотчётов) — без редеплоя.
- Добавление VK-канала **выбором из списка бесед**; **счётчики и последние сигналы** по рассылке.

## Установка

```bash
cd /home/tony/projects/alpine-danil-lite
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполни значения (или используй готовый .env)
```

В `.env` обязательно укажи `ADMIN_CHAT_IDS` — свой Telegram chat_id (узнать: напиши
боту, затем посмотри в логах апдейт, или используй @userinfobot).

## Запуск

```bash
python main.py
```

Источники при первом старте засеиваются из `sources.json` (две рассылки `id1631660353`).
Дальше управляй ботом.

### systemd

```bash
mkdir -p logs
sudo cp alpine-danil-lite.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now alpine-danil-lite
journalctl -u alpine-danil-lite -f
```

## Управление ботом (инлайн-кнопки)

Команд нет — всё через кнопки. Напиши боту любое сообщение → главное меню.
Доступ только у `ADMIN_CHAT_IDS`.

```
🎯 Главное меню
 ├─ ⏸ Пауза опроса / ▶️ Возобновить      — глобальный стоп/старт всего опроса (переживает рестарт)
 ├─ 📋 Рассылки → [рассылка]
 │     ├─ ▶️/⏸ вкл-выкл этой рассылки
 │     ├─ 📡 Каналы доставки → [канал]
 │     │       ├─ сигналы вкл/выкл, отчёты вкл/выкл
 │     │       ├─ 🧪 Тест доставки — шлёт реальное тестовое сообщение в этот канал
 │     │       └─ 🗑 удалить канал
 │     │     → ➕ TG-канал / ➕ VK-беседа (chat_id присылаешь ответным сообщением)
 │     ├─ 📊 Отправить отчёт (день/неделя/месяц) — уходит в очередь poll-loop
 │     └─ 🗑 Удалить рассылку
 ├─ ➕ Добавить рассылку                  — присылаешь URL рассылки ответным сообщением
 ├─ 🔑 Перелогиниться в alpinbet          — форс-релогин руками
 └─ ℹ️ Статус                             — опрос, аптайм, состояние логина, счётчики за сегодня, по рассылкам
```

`chat_id` для TG-канала — вида `-100…`; для VK — `peer_id` беседы (обычно `2000000000+chat_id`).

### Уведомления админам

Бот сам пишет в `ADMIN_CHAT_IDS`, когда сигналы перестают идти: троттлинг/блокировка
(Cloudflare, HTTP 403/429/503), слетевший логин, недоступность сети или любая
повторяющаяся ошибка опроса. С антиспамом (`ALERT_REPEAT_MINUTES`, по умолчанию 15) и
авто-сообщением **«снова онлайн»** при восстановлении.

## .env

См. `.env.example`. Ключевое: креды ЛК, `TELEGRAM_BOT_TOKEN`, `VK_USER_TOKEN`,
`ADMIN_CHAT_IDS`, `PARSER_INTERVAL_SECONDS` (мин. 10), часы отчётов `*_STATS_SEND_HOUR_MSK`.
`PARSER_SEND_EXISTING_ON_START=0` — на старте уже активные матчи помечаются виденными
(не спамим), `=1` — рассылаются сразу. `ALERT_REPEAT_MINUTES` (по умолч. 15) — как часто
повторять уведомление админам об одной и той же проблеме.

## Архитектура

```
main.py            poll-loop (опрос + планировщик отчётов + пауза + очереди + алерты + watchdog)
                   + sender-worker (асинхронная отправка) + bot-loop
alpine_lite/
  config.py        .env
  netfix.py        force IPv4 (обход мёртвого IPv6 к api.telegram.org)
  alpinbet.py      вход/релогин + парс прогнозов (с image_url) + парс таблиц прибыли
  notifier.py      тексты сигналов и отчётов
  senders.py       TG (sendPhoto/editCaption/sendMessage, retry_after) + VK + notify_admins + getConversations
  store.py         sqlite: sources / destinations / signals / stats_sent / settings
  runner.py        проход по рассылке: ставит задания отправки в очередь воркера
  sending.py       SenderWorker: поток-воркер отправки (сигналы/итоги/отчёты)
  reports.py       суточный/недельный/месячный отчёт + расписание МСК (часы из settings)
  runtime.py       разделяемый статус (аптайм/цикл/логин) + sd_notify (systemd watchdog)
  bot.py           инлайн-кнопки: пауза, релогин, тест доставки, VK-список, настройки, статус
tests/             pytest: парсер, периоды, стор
```
